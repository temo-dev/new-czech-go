03 · User flow

Happy path + edge paths

Learner flow theo course pool, không xuất hiện trong MockTest exam pool. Submit fail không mất text đã gõ.

Happy path

  1. Home → Course → Module "Trong quán cafe"
  2. Filter pill Viết → ExerciseListScreen
  3. Tap "Chính tả: Trong quán cafe" → DictationExerciseScreen
  4. Câu 1/6 audio auto-plays. Học viên gõ. Tap Tiếp →
  5. … loops 1–6 …
  6. Câu 6/6: Tiếp → đổi thành Nộp bài
  7. Tap Nộp bài → POST /v1/attempts/:id/submit-text với {sentences: [...]}
  8. AnalysisScreen (orbiting ring) poll GET /v1/attempts/:id
  9. status=completed → DictationResultScreen → 3 tabs
  10. Tap "Hoàn thành" → pop về ExerciseListScreen

Edge paths

  1. Audio 404 → audio card hiện retry button; typing không bị block; submit cho phép kèm cảnh báo
  2. Hết lượt repeat → nút Repeat disabled + tooltip "Hết lượt. Cứ viết theo trí nhớ rồi xem đáp án sau."
  3. App background → text giữ qua AutomaticKeepAliveClientMixin; audio pause; replay-counter giữ in-memory
  4. Submit network fail → banner Retry; không mất text đã gõ
  5. LLM fail → result vẫn hiện score deterministic + diff thô; banner "Phản hồi chi tiết tạm không khả dụng"
  6. TextField > 200 chars → soft warn 180; hard stop 200; toast "Câu quá dài"
  7. Paste từ clipboard → cho phép (V1 không có anti-cheat)
